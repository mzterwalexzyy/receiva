# Three-minute demo

Use actual deployed transaction receipts. The illustrative landing-page example uses 1,000 USDG, while the faucet-friendly onchain script uses 10 USDG.

0:00-0:20: Explain the supplier's working-capital problem and the three roles.

0:20-0:50: Show supplier creation, local PDF hash and buyer approval with a partial bond. Explain that financial terms are public but the PDF stays local.

0:50-1:20: Show the funder advancing USDG, the supplier balance change and the recorded funder address.

1:20-1:45: Open Security Lab on a funded invoice. Run second funding and post-funding cancellation checks. Say explicitly that these are RPC simulations of the deployed contract, not mined transactions.

1:45-2:10: Show on-time settlement and its explorer receipt. Point out the bond return and buyer history.

2:10-2:35: Show the accelerated second invoice's default event, bond payment, outstanding remainder and late cure.

2:35-2:55: Show contract source verification, test evidence and the real-versus-simulated table. State that business identities are demonstrations and offchain debt enforcement is future work.

Record only after replacing pending deployment and verification items with actual evidence. Keep private keys and environment files out of the recording.
