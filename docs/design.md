# Receiva interface direction

A calm working-capital workspace, built around an invoice ledger and a visible path from approval to repayment.

Palette: paper #ffffff, canvas #f5f7f6, ink #172822, muted #64736c, border #dfe6e1, green #176b46.

Typography: Segoe UI for controls and body, Georgia for the large landing headline. Figures use tabular numerals. Left-aligned content, readable line lengths and strong focus indicators.

Desktop: narrow navigation rail, compact network and wallet header, spacious content, a main invoice ledger beside a funding explanation. Mobile: top navigation wraps, forms and ledgers stack, all actions remain reachable.

The memorable element is an invoice sheet with its face value split into advance, return and bond. No decorative gradients. Status names accompany color. Live onchain data and illustrative figures always have separate labels.

Respect the supplied white, grey and green brief. Use simple invoice-specific copy, no fake activity, no fabricated balances. Unconfigured and disconnected states explain the next action.
